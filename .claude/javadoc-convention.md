# Javadoc 주석 규약

Vote 도메인 서비스를 기준으로 정의한 프로젝트 전체 Javadoc 규약.

---

## 작성 대상

서비스 레이어(`@Service`)의 **모든 메서드**에 작성한다.

| 대상 | 작성 여부 |
|---|---|
| 서비스 메서드 (public / private) | **필수** |
| 클래스 레벨 | 생략 |
| 내부 타입 (record 등) | 생략 |

---

## 요약 문장 (첫 줄)

- 한국어, 서술어로 끝나는 **단문** 한 줄
- 마침표로 종결
- 주어는 생략 (메서드 시그니처에 이미 있음)

```java
// 좋은 예
/** 투표에 등록된 모든 참여자를 삭제한다. */

// 나쁜 예 — 주어 중복
/** 이 메서드는 투표에 등록된 모든 참여자를 삭제합니다. */
```

---

## `<p>` 보충 설명

비즈니스 규칙, 제약 조건, 비자명한 동작이 있을 때만 추가한다.

```java
/**
 * 투표 참여자의 참석 가능한 시간 슬롯을 갱신한다.
 *
 * <p>기존 참석 가능 기록을 모두 삭제한 후 요청된 시간 슬롯으로 다시 저장한다.</p>
 */
```

---

## `@param`

- 모든 파라미터에 작성
- 마침표 없음
- 파라미터가 **무엇인지** 서술 (용도가 아닌 의미)

```java
// 좋은 예
@param vote 참여자를등록할 투표
@param teamMemberIds 투표 대상으로 지정할 팀 멤버 ID 목록

// 나쁜 예 — 타입 반복
@param vote Vote 엔티티
```

---

## `@return`

- 마침표 없음
- `boolean`은 아래 형식으로 고정

```java
// 일반
@return 날짜 오름차순으로 정렬된 후보 날짜 목록

// boolean 고정 형식
@return 투표 대상자이면 {@code true}, 그렇지 않으면 {@code false}
```

---

## `@throws`

- `RestApiException`만 문서화
- 여러 조건은 쉼표 또는 `또는`으로 연결, 마침표로 종결

```java
@throws RestApiException 팀을 찾을 수 없는 경우
@throws RestApiException 투표를 찾을 수 없거나 사용자가 팀 멤버가 아닌 경우,
 *                       또는 투표 삭제 권한이 없는 경우
```

---

## 인라인 태그

| 태그 | 사용 시점 | 예 |
|---|---|---|
| `{@code}` | 리터럴 값, 파라미터명 참조 | `{@code true}`, `{@code null}` |
| `{@link}` | 다른 타입·상수 참조 | `{@link EventRole#HOST}` |

---

## 태그 순서

```
요약 문장

<p>보충 설명</p>   ← 필요한 경우만

@param
@return
@throws
```

---

## 작성하지 않는 것

- `@author`, `@version`, `@since` — 버전 관리는 Git에서
- 코드를 그대로 설명하는 주석 — 메서드명·파라미터명이 이미 설명하는 내용
